# ระบบจองโต๊ะอ่านหนังสือในห้องสมุด (Library Study Table Booking System)

แอปพลิเคชันแบบ Command-Line Interface (CLI) ที่เขียนด้วยภาษา Python สำหรับให้นักศึกษาดูสถานะ จอง และจัดการโต๊ะอ่านหนังสือในห้องสมุดได้อย่างง่ายดาย

คุณสมบัติ (Features)

* **ดูสถานะโต๊ะ (Show Table Status): ดูสถานะว่าง/ไม่ว่าง แบบเรียลไทม์ของโต๊ะทั้งหมด (1-5) ใน 3 ช่วงเวลา พร้อมแสดงผลด้วยสีบนเทอร์มินัล (สีเขียวคือว่าง สีแดงคือถูกจองแล้ว)
* **จองโต๊ะ (Book a Table):** นักศึกษาสามารถจองโต๊ะโดยใช้รหัสนักศึกษา 8 หลัก เลือกโต๊ะ และเลือกช่วงเวลาที่ว่าง ระบบจะป้องกันการจองซ้ำซ้อนในโต๊ะและช่วงเวลาเดียวกัน
* **ดูการจองของฉัน (View My Bookings):** ตรวจสอบรายการจองปัจจุบันที่ยังใช้งานอยู่โดยใช้รหัสนักศึกษา
* **ยกเลิกการจอง (Cancel a Booking):** ยกเลิกการจองได้อย่างปลอดภัยโดยใช้รหัสการจอง (Booking ID) ควบคู่กับรหัสนักศึกษาที่ตรงกัน
* **ดูประวัติการจอง (View Booking History):** บันทึกประวัติการจองและการยกเลิกทั้งหมดพร้อมระบุเวลาและวันที่ (Timestamp) โดยจะถูกบันทึกลงในไฟล์ในเครื่องของคุณ

## สิ่งที่ต้องเตรียม (Prerequisites)

* ติดตั้ง Python 3.x บนระบบของคุณ
* เทอร์มินัล (Terminal) หรือคอมมานด์พรอมต์ (Command Prompt) ที่รองรับ ANSI escape codes พื้นฐาน (เพื่อให้แสดงข้อความที่มีสีได้)

## การติดตั้งและการตั้งค่า (Installation and Setup)

1. โคลน (Clone) หรือดาวน์โหลดไฟล์ของโปรเจกต์นี้ลงในเครื่องของคุณ
2. หากคุณใช้งานบนระบบปฏิบัติการตระกูล Unix (เช่น Linux หรือ macOS) ให้ตรวจสอบให้แน่ใจว่าไฟล์สคริปต์ (เช่น `booking.py`) มีสิทธิ์ในการรัน (Execution permissions):

   ```bash
   chmod +x booking.py
   ```

## วิธีการรันโปรแกรม (How to Run)

รันสคริปต์ผ่านเทอร์มินัลของคุณ:

```bash
./booking.py
```

## คู่มือการใช้งาน (Usage Guide)

เมื่อรันโปรแกรม คุณจะพบกับเมนูหลักดังนี้:

```text
==============================
 LIBRARY TABLE BOOKING SYSTEM
==============================
1. Show table status
2. Book a table
3. View my bookings
4. Cancel a booking
5. View booking history
6. Exit
```

พิมพ์ตัวเลขที่ตรงกับเมนูคำสั่งที่คุณต้องการใช้งานและกด **Enter** จากนั้นทำตามคำแนะนำบนหน้าจอเพื่อกรอกข้อมูล เช่น รหัสนักศึกษา (ต้องมี 8 หลักพอดี) การเลือกหมายเลขโต๊ะ และการเลือกช่วงเวลา

ไฟล์ที่ระบบสร้างขึ้น (Files Generated)

* `booking_history.txt`: ไฟล์นี้จะถูกสร้างขึ้นโดยอัตโนมัติในโฟลเดอร์เดียวกันกับตัวสคริปต์ ทำหน้าที่เป็นล็อก (Log) บันทึกประวัติการทำรายการ โดยระบบจะเพิ่มข้อมูลใหม่ต่อท้ายทุกครั้งที่มีการจองหรือยกเลิกการจอง
